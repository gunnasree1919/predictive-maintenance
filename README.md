# Predictive Maintenance for Manufacturing Equipment using Machine Learning

## Overview
This project implements a machine learning-based predictive maintenance system to forecast equipment failures using historical sensor data. The goal is to reduce unexpected downtime and improve maintenance planning in industrial environments.

## Features
- Data preprocessing and cleaning using Pandas and NumPy
- Exploratory data analysis using Matplotlib and Seaborn
- Machine learning model training using scikit-learn
- Failure prediction using trained classification model
- Interactive visualization using Streamlit dashboard

## Tech Stack
Python  
Pandas  
NumPy  
Matplotlib  
Seaborn  
scikit-learn  
Streamlit  

## Project Workflow
1. Dataset collection and preprocessing
2. Feature selection and analysis
3. Model training and evaluation
4. Failure prediction using trained model
5. Deployment using Streamlit interface

## Files Included
- predictive maintenance.ipynb → Model development notebook
- app.py → Streamlit deployment script
- predictive_model.pkl → Saved trained model
- Maintenance_dataset.csv → Dataset used

## Outcome
The system predicts potential equipment failures in advance, helping industries perform proactive maintenance and reduce downtime.
